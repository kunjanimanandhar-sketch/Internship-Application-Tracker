# Internship Application Tracker

A Java-based command-line application for managing and tracking internship applications.

## Features

- Add internship applications
- View all saved applications
- Search for applications by company
- Update application status
- Delete applications
- Save application data to a file
- Automatically load saved applications when the program starts
- Validate menu input

## Technologies

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- File I/O
- Exception Handling
- Git
- GitHub

## How It Works

The application allows users to create and manage internship application records containing:

- Company
- Position
- Application Status

Application data is stored locally in `applications.txt`, allowing information to persist after the program is closed.
